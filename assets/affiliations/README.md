# Affiliation Logos

These white-backed PNG wordmarks identify author affiliations in the main
README. Colors and proportions are preserved; the artwork was rasterized or
downscaled for display. White padding around each wordmark keeps its background
from touching the artwork. The full-width banner combines these same wordmarks
on a continuous white background, ordered Meta, MSU, UW, then UIUC. The logos do
not imply endorsement or approval.

## Sources

- `msu.png`: Michigan State University wordmark, from the source file
  https://en.wikipedia.org/wiki/Special:Redirect/file/Michigan_State_University_logo.png
- `meta.png`: Meta logo reused from Meta FAIR manuscript-template artwork.
  Institution homepage: https://about.meta.com
- `uw.png`: University of Washington signature, from the source file
  https://en.wikipedia.org/wiki/Special:Redirect/file/University_of_Washington_signature.svg
- `uiuc.png`: University of Illinois Urbana-Champaign wordmark, from the source file
  https://en.wikipedia.org/wiki/Special:Redirect/file/University%20of%20Illinois%20at%20Urbana-Champaign%20Wordmark.svg
